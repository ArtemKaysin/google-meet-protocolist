# Доступ проекта к Google

- Работай от имени существующего Google-аккаунта пользователя. Для данных Calendar, Drive и Meet используй веб-сессию этого аккаунта и проверенные запросы веб-интерфейсов Google.
- После входа выполняй запросы напрямую из локального HTTP-клиента. Открывай браузер для подтверждения входа или для сетевой трассировки, когда её просит пользователь.
- Для этого проекта не настраивай приложения Google Cloud, сервисные аккаунты или отдельный OAuth-доступ к публичным API Google. Если прямой веб-запрос пока не подтверждён, явно укажи ограничение.
- Сверяй аккаунт перед использованием сессии. Храни cookies только в защищённом локальном хранилище, исключай их из вывода, логов и Git.
